```python
class IntroductionToTriangles(Scene):
    def construct(self):
        # Triangle Creation
        triangle = Polygon([-2, -1, 0], [2, -1, 0], [0, 2, 0], color=WHITE)
        A_label = MathTex("A", font_size=24)
        B_label = MathTex("B", font_size=24)
        C_label = MathTex("C", font_size=24)

        # Positioning Labels
        A_label.next_to(triangle.get_bottom(), UP + LEFT * 0.5, buff=0.3)
        B_label.next_to(triangle.get_right(), UP + RIGHT * 0.3, buff=0.3)
        C_label.next_to(triangle.get_top(), UP + RIGHT * 0.5, buff=0.3)

        # Group Triangle and Labels
        triangle_group = VGroup(triangle, A_label, B_label, C_label)

        # Properties Text
        text = Tex("Triangles have three sides and three angles.", font_size=24)
        text.next_to(triangle, DOWN, buff=0.5)

        # Animation Sequence
        self.play(Create(triangle_group, run_time=2))
        self.play(Write(A_label, run_time=1))
        self.play(Write(B_label, run_time=1))
        self.play(Write(C_label, run_time=1))
        self.play(FadeIn(text, run_time=1))
        self.wait(2)
        self.play(FadeOut(text))

        # Exiting the scene
        self.wait(0.5)
```

***Mandatory Safety Checks***:
    - **Safe Area Enforcement**: All objects, including text bounding boxes, must remain within 0.5 unit margins.
    - **Minimum Spacing Validation**: Confirm a minimum of 0.3 units spacing between every pair of objects.
    - **Transition Buffers**: Use explicit `Wait()` calls to separate animation steps and sub-scenes.
